Works with Moodle XML made of description questions (content, with embedded images) alternating with multichoice questions. Everything runs in your browser — nothing is uploaded.

You can also point the page straight at a file with a URL parameter: ?xml=lesson.xml (a file beside this page) or ?xml=https://host/quiz.xml (anywhere online).
